# 색상 팔레트와 PDF 내보내기 개선 — 2026-10-22

요청한 색상 팔레트와 이전 검토에서 우선순위가 높았던 글꼴 일치, OCR 검색 PDF 내보내기를 함께 적용했습니다. 이전에 복원한 헤더 메뉴 구성을 유지했습니다.

## 적용 내용

- **색상 팔레트:** 테마 10열 × 6행과 표준 색 10개, 총 70개 색상을 표시합니다. 현재 색 표시와 HEX 안내, 사용자 지정 색상 선택을 지원합니다. 선/도형, 채우기, 텍스트 색상에 같은 팔레트를 사용합니다.
- **편집 흐름:** 텍스트를 선택하고 색상을 바꿀 때 선택 영역을 유지합니다. 방향키와 Home/End로 이동하고 Enter/Space로 선택하며, Escape는 팔레트만 닫습니다. 창 크기와 도구/문서 전환에 맞춰 팝업 위치와 닫힘을 처리합니다.
- **화면과 PDF 글꼴 일치:** Noto Sans KR와 Noto Serif KR의 일반체·굵은 글꼴을 앱에 포함하고 화면과 PDF에 같은 파일을 사용합니다. 내보내기 전에 글꼴 로딩을 기다리며, 한글 주변 공백 폭과 기울임 각도를 맞췄습니다. 기존 시스템 글꼴 이름은 지원하는 두 계열로 대체하며 툴팁으로 안내합니다.
- **검색 가능한 OCR PDF:** OCR을 완료한 뒤 기존 ‘내보내기’를 사용하면 완료된 페이지의 인식 텍스트를 보이지 않는 PDF 텍스트 레이어에 포함합니다. 내보낸 파일에서 텍스트 검색·선택·복사가 가능합니다. 원래 PDF의 보이는 내용과 기존 텍스트를 유지하며, 편집 중인 원본의 경로·수정 상태를 바꾸지 않습니다.

## 확인 결과

- 전체 자동 테스트: **82 통과, 실패 0, 건너뜀 0**. 최종 변경 후 `sl run_tests --full` 실행, 5.6초.
- 프로덕션 빌드: `npm run build` 성공. 렌더러와 Electron TypeScript 검사를 포함하며 Vite 빌드는 3.32초.
- 실제 Electron 창: 마우스/방향키/Enter 색상 선택과 사용자 지정 색상 적용 시 선택한 텍스트 유지, 로컬 Escape 처리, 바깥 클릭 및 문서/도구 문맥 전환 시 닫힘을 확인했습니다. 720px/1280px 창에서 70개 색상과 헤더 컨트롤의 가로 넘침이 없었습니다.
- 글꼴: 네 가지 얼굴의 오프라인 로딩과 24px 한글·영문 혼합 문장의 폭을 비교했습니다. 실제 DOM과 PDF 글꼴 엔진의 차이는 0.01px 미만이었으며, 실제 기울임 도구 적용 결과도 12도로 일치했습니다.
- OCR: PDF.js로 한글·영문, 공백·줄바꿈 추출과 잘린 페이지 및 0/90/180/270도 회전 좌표를 확인했습니다. OCR 레이어 추가 전후 렌더링 픽셀은 동일했습니다. 완료 페이지 스냅샷과 원본 상태 보존도 테스트했습니다.
- 기존 플로팅 메뉴: 720px/1280px에서 레이아웃 이동 0, 모션 감소 설정의 애니메이션 시간 0초를 재확인했습니다.
- 최종 코드 검토에서 발견한 Tab 이동 문제를 수정했습니다. 실제 창에서 Tab으로 ‘다른 색…’ 입력 접근, Shift+Tab으로 색상 복귀, Tab으로 바깥 이동 시 닫힘을 확인했습니다.
- Mac arm64 앱 패키징 성공. 최종 패키지의 sandbox preload, PNG 클립보드, PDF.js 렌더링, 오프라인 한글·영문 OCR, 회전/저장/내보내기, 스크롤·탭·이동 복원을 확인했습니다.

## 동작 범위와 비용

- OCR을 자동 실행하지 않습니다. 인식이 끝난 페이지를 내보내기에 포함하며, 진행 중이거나 인식하지 않은 페이지는 원래 상태를 유지합니다.
- 기존 PDF 텍스트와 OCR 결과의 중복 제거는 이번 범위에서 제외했습니다. 이미 텍스트가 있는 페이지에 OCR을 실행하면 내보낸 PDF에 중복 텍스트가 생길 수 있습니다.
- 임의의 시스템 글꼴을 그대로 유지하는 대신 두 개의 한글 지원 글꼴 계열로 통일했습니다. 기존 문서의 글꼴 모양이 달라질 수 있습니다.
- 한글 글리프가 깨지지 않도록 사용한 글꼴을 전체 포함합니다. 특히 Serif를 포함한 PDF는 파일 크기가 커질 수 있고, 앱에도 네 개의 글꼴 자산이 포함됩니다. 새 런타임 라이브러리는 추가하지 않았습니다.
- macOS arm64에서 실제 실행과 패키징을 확인했습니다. Windows 실제 실행 및 외부 PDF 뷰어별 수동 검증은 아직 수행하지 않았습니다. OCR 텍스트 추출과 화면 일치는 PDF.js 기반으로 검증합니다.
