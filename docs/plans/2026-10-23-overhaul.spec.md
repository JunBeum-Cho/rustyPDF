# RustyPDF overhaul spec

Source: code review of `305373c` (sections 1–3 of the report, numbered the same way here) and the user's choices on 2026-10-23. Every task reads **Decisions**, **Shared contracts** and its own § items.

## Decisions

- D1 Annotations are saved inside the PDF as standard PDF annotations (/Annot) with appearance streams, plus a `/RustyPDF` JSON entry so RustyPDF re-opens them editable. The worker keeps "base bytes" with RustyPDF annotations stripped; PDF.js renders the base and the renderer overlays editable annotations. Old sidecars are read once for migration (read-only). Annotation autosave writes only a crash-recovery draft in userData, never the PDF.
- D2 Per-run rich text in text annotations stays; it is tidied (§1.6).
- D3 Deploy items: config/code skeletons that stay off without certificates or an update server. App name and app ID stay.
- D4 Units: `tab.zoom` is the user zoom shown as %. CSS px per PDF point = `zoom * 4/3` (`pxPerPt`). 100% means real size at 96 dpi.
- D5 `Tab.rotation` (transient view rotation, always 0) is removed everywhere.
- D6 One undo history per tab (annotation and page entries in one stack).
- UI strings are Korean. Error messages shown to users are Korean.

## Shared contracts

#### C1 Types (src/annotations/types.ts, src/state/document.ts)
- `AnnotationKind` adds `"underline" | "strikeout"`. `Annotation` adds `quads?: Rect[]` (page points, top-left origin, same space as `rect`). Markup made from a text selection has `quads`, and `rect` = their bounding box. A drag-drawn highlight has only `rect`.
- `Tab`: remove `rotation` and `annotationDocumentKey`; add `readOnly: boolean`, `readOnlyReason: "encrypted" | null`, `signed: boolean`, `formDirty: boolean`.
- `AnnotationTabState`: remove `history` and `future`. Keep the other fields.
- `DocumentHistoryEntry = {kind: "annotation"; items: Annotation[]} | {kind: "page"; token: string; snapshot: PageEditSnapshot}`, where `items` is the annotation list before the edit. `PageEditSnapshot = {items: Annotation[]; selectedPageIndices: number[]; pageAnchor: number | null; currentPage: number}`. At most 80 entries per stack.

#### C2 Worker commands (`electron/protocol.ts` lists exactly these)
Document commands take `{docId, expectedRevision}` plus the listed fields.
`DocPayload = {id, revision, path, pageCount, pages: PageMeta[], fileSize, readOnly: boolean, readOnlyReason: "encrypted" | null, signed: boolean}`.
`EditPayload = DocPayload & {pageMapping: (number | null)[], historyToken?: string, retainedHistoryTokens: string[]}`.

| pdf_document_bytes | doc | Uint8Array (base bytes) |
| pdf_create_from_images | {paths, name} | DocPayload (unsaved://) |

Main-only commands: initial_open_paths, request_app_exit, note_recent_document, clipboard_write_png {bytes}, print_images {pages: {png: Uint8Array; widthPt: number; heightPt: number}[], title} → boolean, open_external {url} (http, https, mailto only), paths_exist {paths} → boolean[], draft_write {path, json}, draft_read {path} → string | null, draft_delete {path}.

Read-only documents reject edits/save/export/flatten/form apply with "암호화된 PDF는 읽기 전용이라 편집하거나 저장할 수 없습니다."

#### C3 Path grants (main)
Main keeps a set of granted absolute paths: open/save dialog results, OS-open paths (argv, open-file, second-instance), and dropped files (preload `filePath(file)` also sends `desktop:grant` with the non-empty path). `desktop:read` needs a granted path; `desktop:write` needs a granted save-dialog path. `pdf_open` accepts any absolute `.pdf` path. Save: if `targetPath` is not granted, main adds `requireCurrentPath: true` and the worker rejects any target other than the document's path. Export targets, image/merge/insert source paths must be granted. Pure logic lives in `electron/grants.ts`. Before `pdf_create_from_images`, main converts non-PNG/JPEG files with `nativeImage` into PNG temp files; on failure: "이 이미지 형식은 이 컴퓨터에서 지원되지 않습니다: <name>".

#### C4 Renderer engine (`src/platform/pdf-engine.ts`)
```ts
export function pdfEngine(): PdfEngine
type PasswordProvider = (docId: string, retry: boolean) => Promise<string | null>
class PdfEngine {
  getDocument(docId: string, revision: number): Promise<PDFDocumentProxy>
  openBytes(bytes: Uint8Array): Promise<PDFDocumentProxy>           // caller destroys
  renderPage(canvas: HTMLCanvasElement, req: {docId: string; revision: number; pageIndex: number; cssWidth: number; cssHeight: number; dpr: number}): {promise: Promise<void>; cancel(): void}
  capture(docId: string, revision: number, region: {pageIndex: number; x: number; y: number; w: number; h: number; scale?: number}): Promise<ArrayBuffer> // x..h normalized 0..1 of the displayed page
  recognizePage(docId: string, revision: number, pageIndex: number): Promise<OcrPagePayload>
  pageHasText(docId: string, revision: number, pageIndex: number): Promise<boolean>
  setPasswordProvider(provider: PasswordProvider): void
  close(docId: string): void
}
```
`renderPage` draws straight into the given canvas with pixel size `css * dpr`, bounded to 16M pixels, `annotationMode: AnnotationMode.ENABLE_FORMS`, white background. `src/platform/desktop.ts` `invoke` sends every command to the bridge (no engine routing) and calls `pdfEngine().close(docId)` after pdf_close and after mutation commands. It imports no viewer module.

#### C5 Viewer layout
`navigation.ts` exports `pxPerPt(zoom)`, `ZOOM_STEPS`, `zoomIn()`, `zoomOut()`, `setManualZoom`, `navigateToPage`, and `fitZoom(mode, viewW, viewH, pageW, pageH)` (in pt; returns user zoom). Width mode uses the widest page; page mode uses the largest page. `PageCanvas` props: `{page, index, width, height, docId, revision, contentVersion, scale}` (`scale` = px per pt). `PageCanvas` mounts, in order: canvas, `TextLayer {pageIndex, page, revision, contentVersion, zoom: scale}`, `PdfAnnotationOverlay {docId, revision, pageIndex, scale}`, `AnnotationLayer {page, width, height, zoom: scale}`. `ui.ts` adds `invertPagesInDark: boolean` (default false) and `sidebarMode: "thumbnails" | "outline"`.

#### C6 History and store
`recordAnnotationHistory()` pushes `{kind: "annotation", items}` and clears the redo stack. Undoing a page entry calls `pdf_restore_snapshot {token}`, restores the snapshot items and selection, and pushes the reverse entry with the same token. While a restore is in flight, `historyBusy()` is true and annotation mutators are no-ops. `addAnnotationToTab(tabId, annotation)` records history on that tab and marks it dirty. `enqueueDocumentMutation` runs every hook registered with `registerPreMutationHook(hook)` for the tab before the task.

#### C7 Document flows (`src/ipc/pdf.ts`)
`openPdf` activates an existing tab that has the same `payload.id`. Tab annotations come from `payload.annotations ?? payload.legacy?.annotations ?? []`. Legacy annotations mark the tab dirty and show "이전 버전 주석을 불러왔습니다. 저장하면 PDF 안에 함께 저장됩니다." `buildAnnotationPayload(tab)` waits for fonts and returns a sidecar with measured text layout and normalized images; save, export and print use it. Save asks once per signed tab: "전자 서명이 있는 PDF입니다. 저장하면 서명이 무효가 될 수 있습니다. 계속할까요?" Read-only tabs never save. Drafts: 1 s after the last annotation edit of a dirty tab with a real path, `draft_write`. On open, a newer draft offers "복구" in a toast. A successful save calls `draft_delete`. `addDocumentTab(payload, {annotations, unsaved})` creates and activates a tab. On `pdf-service-restarted`, real-path tabs are re-opened (annotations kept) and "PDF 엔진이 다시 시작되어 저장하지 않은 페이지 편집이 취소되었습니다." is shown. On `document-changed-on-disk`, a toast offers "다시 불러오기" ("변경 사항 버리고 다시 불러오기" when dirty).

#### C8 Annotation codec (worker)
`writeAnnotations` maps text→FreeText, rect→Square, ellipse→Circle, line/arrow→Line (arrow `/LE [/None /ClosedArrow]`), pen→Ink, highlight/underline/strikeout→Highlight/Underline/StrikeOut (`/QuadPoints` from quads or rect), image→Stamp. Every annotation has `/Rect`, `/C`, `/CA`, `/F 4`, `/NM (rustypdf-<id>)`, `/RustyPDF` (JSON of the annotation without `payload.layout`) and `/AP /N` from `buildAppearance`. Export flattening draws the same appearance XObjects into the page content. Arrow heads are filled triangles (length 9×stroke, half-width 3×stroke), the same on screen and in output. Ink is one stroked path. Highlight quads use `/BM /Multiply`. Fonts: `createFontProvider(pdf, text, fontsDir?)` embeds a harfbuzz subset of the bundled face that covers `text`. OCR invisible text is wrapped in `/RustyOCR BMC … EMC`.

## 1. Over-engineering

### 1.1 Render path
Remove the RGBA/`pdf_render_page` emulation and render PDF.js straight into the visible canvas (C4); remove the fake commands and their routing; drop Pdfium/Tauri comments.

### 1.2 Undo protocol
Delete `pendingRestore`, `pdf_accept_restore`, `pdf_rollback_restore` and `documentHistoryRecovery.ts`; unify history (C1, C6); page snapshots hold only items, selection and current page.

### 1.3 Annotation identity
Replace the alias/fingerprint/documentKey store with D1. `annotation-store.ts` becomes a read-only legacy loader `loadLegacy(path, bytes)` (exact path or unique moved match, current and legacy roots, adjacent `.notes.json`) that never writes.

### 1.4 PDF.js re-implementations
Use the PDF.js `TextLayer` for native text and a PDF.js-style text join (items concatenated, `\n` only at `hasEOL`) for search.

### 1.5 Duplicate queues
`electron/worker.ts` stops queueing (the service serializes); drop the redundant re-check in `pdf_ocr_page`.

### 1.6 Rich text tidy
Replace `execCommand` for color, size and font with a Range-based `applyInlineStyle`; bold/italic/underline go through one helper; paste keeps `insertHTML` for native undo (documented). Remove duplicated helpers.

### 1.7 Dead code and duplicates
Remove: `copyDeferredPngToClipboard`, `markAnnotationsSavedForTab`, `replaceAnnotationsForTab`, `buildAnnotationSidecar`, `flushActiveAnnotationSave`, `guardActiveTabUnsaved`, `promptUnsavedChanges`, `FileDropHandlers`, `dropPosition.ts`, `set_dock_recents` with `syncDockMenu`, the duplicate `addRecentDocument` in `pdf_open`, `requestOpenPdf` and `requestOpenPdfDialog` (callers use `openPdf` and `openPdfDialog`), duplicate `ZOOM_STEPS` and zoom helpers, duplicate `paintRgba` and `isEditableTarget`, `Tab.rotation` (D5).

### 1.8 Smoke and source-regex tests
Move the smoke run from `electron/main.ts` to `electron/smoke.ts` and load it only when `RUSTYPDF_SMOKE` is set; rewrite `tests/renderer-state.test.ts` as behavior tests.

## 2. Bugs

### 2.1 Area capture
Normalize the dragged rect by the displayed page size before `capture`; copy the PNG to the clipboard at once and show a toast with "파일로 저장".

### 2.2 Sticky page selection
Page shortcuts work only while focus is inside `.thumbnail-sidebar`; ⌘C with a non-empty text selection is never intercepted; pointer-down in the page view clears the page selection; deleting pages shows a toast with "실행 취소".

### 2.3 Encrypted PDFs
Open with `ignoreEncryption`, mark read-only, ask for a user password through the engine provider and a password dialog, and disable edit, save and annotation tools with a "읽기 전용" badge.

### 2.4 Duplicate tab per document
Covered by C7.

### 2.5 EXIF orientation
Bake JPEG orientation in when an image is dropped (re-encode through `createImageBitmap` with `imageOrientation: "from-image"`); fix the swapped Orientation 5/7 matrices in the image-to-PDF path.

### 2.6 Image drop undo
Image drop goes through `addAnnotationToTab`.

### 2.7 Arrow head colour
Use a marker per annotation with that annotation's colour; draft marker per page; output matches (C8).

### 2.8 Blurry pages and 100%
Render at CSS size × devicePixelRatio, re-render at the exact scale 150 ms after the last zoom change, and apply D4 to pages and thumbnails.

### 2.9 Fit zoom jumps
Fit zoom uses the widest or largest page, not the current one.

### 2.10 Pinch zoom
Ctrl/⌘+wheel zooms continuously: `zoom *= exp(-deltaY * 0.01)`, clamped to 0.25–4, anchored at the pointer.

### 2.11 Korean IME shortcuts
Compare `e.code` and ignore events while `e.isComposing`.

### 2.12 Search
Match across PDF.js item boundaries and ignore whitespace differences; fetch OCR lines once per revision (`pdf_ocr_all_lines`); show results progressively; OCR progress re-searches only new pages and keeps the active match.

### 2.13 OCR lost on page edits
The worker remaps OCR with the page mapping (rotated pages are dropped) and stores OCR inside history snapshots; the renderer refreshes status instead of clearing it.

### 2.14 OCR cache location and close failures
The OCR cache lives at `<userData>/ocr/<fingerprint>.json` (legacy `<pdf>.ocr.json` is read only); cache write failures are logged and never block close or dispose.

### 2.15 Annotations vanish after external edits
Covered by D1, C7 and C8.

### 2.16 Security boundary
Add a CSP meta tag to `index.html`; enforce path grants (C3); production menus have no reload or devtools.

### 2.17 Crash recovery
The worker client respawns after an unexpected exit (at most 3 times per minute) and main sends `pdf-service-restarted`; an unresponsive renderer gets a native "기다리기 / 강제 종료" dialog; `render-process-gone` lets the app quit or reloads the window.

### 2.18 Autosave writing PDFs
Autosave writes drafts only (C7).

### 2.19 Windows
`EPERM`, `EBUSY` or `EACCES` on the final rename gives "다른 프로그램이 파일을 사용 중이라 저장하지 못했습니다. 그 프로그램을 닫고 다시 시도해 주세요."; no menu bar on Windows and Linux in production.

### 2.20 Size and memory
Subset embedded fonts (C8); package the fonts once (`dist/fonts`, passed to the worker as `fontsDir`); move renderer-only dependencies to devDependencies; page edits load the PDF once.

## 3. UI and features

### 3.1 Print
⌘P and a toolbar button: flatten (or the original for read-only documents), render each page at 150 dpi to PNG with a progress toast, then `print_images` opens the system print dialog from a hidden window.

### 3.2 Outline, links and forms
A sidebar "목차" tab shows `getOutline()`; a PDF.js `AnnotationLayer` overlay handles internal links (navigate), external links (`open_external`) and form widgets. Form edits mark the tab dirty and are applied through `pdf_apply_form_bytes` by a pre-mutation hook. Read-only documents render forms disabled.

### 3.3 Rotate selected pages
The R key, the toolbar button and the thumbnail menu rotate the selected pages (or the current page) instead of the whole document; ⇧R rotates counter-clockwise.

### 3.4 Thumbnail drag reorder
Dragging selected thumbnails shows a drop line and calls `pdf_move_pages`; annotations follow the mapping.

### 3.5 Text-based markup
Selecting PDF or OCR text shows a floating "형광펜 / 밑줄 / 취소선" bar that creates quad-based markup annotations.

### 3.6 Standard annotations
Covered by D1. The save tooltip says annotations are stored inside the PDF.

### 3.7 Merge and extract
Welcome "PDF 합치기" (`pdf_merge_files`); thumbnail menu "새 PDF로 추출" (`pdf_extract_pages`, annotations copied) and "다른 PDF 삽입…" (`pdf_insert_file`).

### 3.8 Viewer polish
The active thumbnail scrolls into view; optional page inversion in dark theme; external-change toast (C7); the thumbnail context menu is clamped to the viewport; thumbnails re-render 200 ms after a sidebar resize ends.

### 3.9 Tabs and recent files
- Tab names: same-name tabs append " — <parent folder>".
- Tab order: drag to reorder.
- Tab context menu: 닫기, 다른 탭 닫기, 오른쪽 탭 닫기, 경로 복사.
- Tab strip: scrolls horizontally with the wheel and keeps the active tab visible.
- Recent files: missing files are dimmed as "파일 없음" (`paths_exist`), and an open failure offers "목록에서 제거".

### 3.10 Editing aids
- Capture: behaves as described in §2.1.
- Shortcut help: ⌘/ or ? opens a dialog of all shortcuts.
- Signature tool: draw pad, image import, up to 5 saved signatures in localStorage; placed as an image annotation.
- Image to PDF:
  - Thumbnails, drag reorder, and the up/down buttons kept.
  - Accepts HEIC/HEIF/WebP/GIF/BMP/TIFF (converted per C3).

### 3.11 OCR
- Whole-document runs skip pages that already have text.
- OCR runs for several documents queue (shown as "대기 중").
- A popover checkbox "저장할 때 인식한 텍스트 포함(검색 가능한 PDF)" (default on, stored in localStorage) feeds `includeOcr` on save.

### 3.12 Deploy skeleton
- Signing and notarization:
  - macOS: hardened runtime, entitlements, and signing/notarization driven by env/secrets (unsigned without them).
  - `electron/updater.ts` `initAutoUpdates()` is a no-op unless the app is packaged and `RUSTYPDF_UPDATE_URL` is set; it loads `electron-updater` lazily and is not a dependency.
- CI:
  - `ci.yml` (PRs and pushes: test, build, smoke on macOS and Windows).
  - `release.yml` (`v*` tags: package and upload).
- Docs: README documents all of this.
